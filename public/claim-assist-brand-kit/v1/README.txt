MyPro Claim Assist - Brand Kit (v1.0, November 2026)
=====================================================

Start with MyPro-Claim-Assist-Brand-Guidelines.pdf for how to use everything here.
Online version: https://myproproducts.com/claimassist/brand

01-Logo
  Horizontal  Primary logo. Use this first, wherever it fits.
  Stacked     For square or tall spaces.
  Mark        The umbrella, house and check on their own (avatars, icons).
  Each comes in four versions:
    color     For white and light backgrounds.
    reversed  For dark backgrounds (deep purple, navy, black, dark photos).
    white     One color, for purple or busy photo backgrounds.
    black     One color, for print, fax and stamps.
  SVG = vector, scales to any size (web, print, signage).
  PNG = transparent background, for documents, slides and social posts.

02-App-Icon
  1024 / 512 / 192 / 180 px square icons: purple tile (main) and white tile.

03-Favicon
  favicon.ico plus SVG and PNG favicons for websites.

04-Colors
  Color values as JSON and as CSS variables.
